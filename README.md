# Desarrollo de aplicaciones móviles para Sistemas Operativos Android Nivel Básico

Este curso introduce al participante al desarrollo de aplicaciones móviles Android utilizando exclusivamente Kotlin. Se estudian los conceptos fundamentales del ecosistema Android, la estructura de una aplicación, sus componentes básicos, los ambientes de desarrollo, interfaces de usuario, manejo de contenido multimedia, persistencia simple y recursos.
A lo largo del curso, los participantes construirán múltiples ejercicios prácticos y desarrollarán un proyecto final que integrará los elementos esenciales de una aplicación Android.

## Estructura

- `CapituloXX/README.md`: guía de laboratorio por capítulo.

## Lista de laboratorios

### Capítulo 1

- [Laboratorio 1: Configuración del entorno y creación de la primera aplicación Android](Capitulo01/README.md#laboratorio-1-configuración-del-entorno-y-creación-de-la-primera-aplicación-android)
  - Descripción: Instalar y verificar Android Studio, crear y configurar un emulador o dispositivo físico, generar un proyecto Android básico en Kotlin, identificar sus archivos y carpetas principales, ejecutar la aplicación y realizar una modificación sencilla para comprobar el flujo de compilación y despliegue.
  - Duración estimada: 144 min

### Capítulo 2

- [Laboratorio 2: Aplicación de fundamentos de Kotlin en un caso práctico](Capitulo02/README.md#laboratorio-2-aplicación-de-fundamentos-de-kotlin-en-un-caso-práctico)
  - Descripción: Desarrollar en Kotlin una pequeña lógica de gestión de datos, por ejemplo un registro de tareas o productos, utilizando variables e inmutabilidad, null-safety, funciones, clases e interfaces, colecciones, condicionales y ciclos, incorporando validaciones y manejo básico de errores.
  - Duración estimada: 216 min

### Capítulo 3

- [Laboratorio 3: Navegación y ciclo de vida entre pantallas Android](Capitulo03/README.md#laboratorio-3-navegación-y-ciclo-de-vida-entre-pantallas-android)
  - Descripción: Construir una aplicación con al menos dos pantallas que permita capturar información en una Activity, enviarla a otra mediante Intents, observar eventos principales del ciclo de vida, conservar datos simples ante cambios de estado e introducir ViewModel para mantener información básica.
  - Duración estimada: 216 min

### Capítulo 4

- [Laboratorio 4: Construcción de una interfaz interactiva con recursos Android](Capitulo04/README.md#laboratorio-4-construcción-de-una-interfaz-interactiva-con-recursos-android)
  - Descripción: Crear una interfaz funcional que combine ConstraintLayout o LinearLayout, TextView, EditText, Button, ImageView y una lista sencilla; gestionar clics y entradas del usuario, separar textos, colores, dimensiones y estilos en recursos, y conectar al menos dos vistas mediante navegación básica.
  - Duración estimada: 288 min

### Capítulo 5

- [Laboratorio 5: Aplicación multimedia con cámara, galería y reproducción de medios](Capitulo05/README.md#laboratorio-5-aplicación-multimedia-con-cámara-galería-y-reproducción-de-medios)
  - Descripción: Desarrollar una aplicación que permita seleccionar o capturar una imagen, mostrarla en pantalla y reproducir un recurso de audio o video. La práctica incluirá solicitud y validación de permisos necesarios y, cuando el dispositivo lo permita, una interacción sencilla con un sensor o servicio.
  - Duración estimada: 216 min

### Capítulo 6

- [Laboratorio 6: Persistencia local de preferencias y datos](Capitulo06/README.md#laboratorio-6-persistencia-local-de-preferencias-y-datos)
  - Descripción: Implementar una aplicación que guarde preferencias del usuario con SharedPreferences o DataStore y almacene información sencilla en archivos internos o externos. Como extensión, identificar cómo esos datos podrían modelarse en una base de datos local.
  - Duración estimada: 144 min

### Capítulo 7

- [Laboratorio 7: Desarrollo e integración del proyecto final Android](Capitulo07/README.md#laboratorio-7-desarrollo-e-integración-del-proyecto-final-android)
  - Descripción: Diseñar, construir y presentar una aplicación final que incluya varias pantallas, navegación, recursos, interacción con el usuario, al menos una función multimedia y persistencia simple. Se realizarán pruebas funcionales básicas y una revisión final del comportamiento de la aplicación antes de su presentación.
  - Duración estimada: 216 min
